About Me

I started writing code as a teenager and turned it into a freelance practice not long after — today I work as a self-employed full-stack web developer out of Karachi, Pakistan. My day-to-day spans the WordPress and WooCommerce ecosystem — Elementor, ShopEngine — for fast client launches, alongside hand-built front ends in HTML, CSS, JavaScript, and jQuery for projects that need more control. On the back end I work with PHP, MySQL, and Python, and I manage the full deployment pipeline myself: Git, Netlify, Hostinger, InfinityFree — so a project goes from local build to live URL without a handoff. I also design before I build, with Figma, Adobe XD, and Photoshop sitting right next to my code editor in my workflow. What sets me apart at this stage is speed and ownership — clients get one person handling design, build, and deployment, not a hand-off between three.
